# 秋招工作台 · 飞书表格同步桥接扩展

## 为什么需要它
飞书多维表格是**需要登录**的私有数据，浏览器有「同源策略」硬性限制：
网页里的 JS **无法**跨域携带另一个网站（feishu.cn）的登录 Cookie，也无法在 iframe 里嵌套飞书页面。
因此纯网页做不到「无感复用飞书登录态」——这是浏览器安全模型的边界，不是代码能绕过的。

**唯一能在「不公开表格权限、不手动导入」前提下实现无感自动同步的方案，就是本机浏览器扩展。**
扩展拥有跨域权限，可以在后台复用你已登录的飞书账号读取表格，再把数据写进工作台。

## 安装（一次即可，约 1 分钟）
1. 把 `feishu-bridge` 整个文件夹保存到本地（比如桌面）
2. Chrome / Edge 打开 `chrome://extensions`
3. 右上角打开「**开发者模式**」
4. 点「**加载已解压的扩展程序**」→ 选中 `feishu-bridge` 文件夹
5. 确认你的浏览器已登录能访问该表格的飞书账号

## 使用
- **自动**：扩展每 30 分钟在后台静默打开一次表格页（约 15 秒后自动关闭），抓到数据后自动写入已打开的工作台；工作台没打开时数据会暂存，下次打开自动应用
- **手动**：点扩展图标 → 「立即抓取表格」/「应用到已打开的工作台」
- 工作台「设置中心 → 飞书多维表格数据同步」卡片会显示桥接状态与最近同步结果

## 工作原理
1. `content.js` 注入飞书页面，监听页面加载表格数据时接口的 JSON 响应，提取记录并扁平化（自动处理飞书的文本/多选/人员/链接等字段类型）
2. `background.js` 定时在后台打开目标表格页 → 等抓取完成 → 关闭标签 → 用 `chrome.scripting` 把记录注入工作台页面
3. 工作台暴露 `window.QZ.applyBridgeRows(rows)`，收到后按字段别名智能归类（岗位/笔试/面试/资源/待办），支持覆盖或增量去重，写入同步日志

## 隐私与安全
- 全部数据只在**你本机浏览器**流转，扩展不向任何第三方服务器发送你的表格数据
- 扩展只申请 `storage / scripting / alarms / tabs` 与 feishu.cn、workbuddy.host 两个域的访问权限
- 表格为只读拉取，不会对你或他人的飞书表格做任何写入

## 兜底
抓不到数据（登录态过期 / 页面结构变化）时：
- 工作台**不会清空任何已有数据**，原有秋招记录完整保留
- 可在设置中心用「粘贴导入」或「导入 CSV 文件」手动兜底更新

## 说明
本扩展为个人自用工具，未经飞书官方 API 授权，内部接口响应结构若发生变化可能需要调整 `content.js` 的提取规则；
如需最正规的方案，可二期改为「飞书开放平台 OAuth + 后端定时同步」（毕设里可以作为技术方案章节写）。
