# 图标资源目录（可选自定义）

## 默认图标
全站 40 个图标位默认使用**内置原创手绘卡通图标**（`data.js` 中的 SVG 图元）：

- 风格：圆角 100% 圆润、块面饱满、线条柔和、无尖锐棱角
- 配色：低饱和马卡龙浅色系（浅青 / 浅粉 / 浅黄 / 浅蓝 / 浅紫 / 浅绿）+ 柔和青灰描边
- 版权：原创绘制，非任何 IP 形象、非通用线性图标、非系统默认图标，**零版权风险，可直接商用**

## 可选：替换为其他可商用开源图标
如果你想换成别的可商用资源（OpenMoji、Twemoji 等 CC0 / MIT / Apache 授权图标包）：

1. 准备 PNG（建议 256×256 以上，透明底）
2. 按下方文件名重命名，放入本目录（与 `README.md` 同级）
3. 刷新页面即全站生效——**不需要改任何代码**
4. 某些图标位没有对应文件时，自动显示内置原创卡通图标，不会出现空白或断图
